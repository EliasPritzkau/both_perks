

# Our task is it to make a Mod for Mount & Blade Bannerlod II. 

- DO NOT EDIT OR ADD TO THE FOLDER MB_source. In there you will find decompiled game files that help you to make the mod. 
- You may look at any other mod in the folder called Modules, one below your current working directory.

## Functionality

- The Mod should automatically assign both Perks to the Player, as soon as they become available.
- Bannerlord perk choices are usually either/or. We now grant both perks in each pair as soon as a character hits the required skill level. 
- This should apply for all Characters/Heros (companions, clan leaders, NPC nobels, Wanderers...) in the game, but not the troops.
- Mod Configuration Menu

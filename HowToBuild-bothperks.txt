BothPerks build workflow
========================

Shared paths are configured in:

  ..\personalTooling\ModPaths.local.psd1

Build this mod from this directory:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\BuildBothPerks.ps1 -ReferenceVersion v1_4

Runtime layout:

  BothPerks.Bootstrap.dll
  compat\v1_2\BothPerks.Core.dll
  compat\v1_3\BothPerks.Core.dll
  compat\v1_4\BothPerks.Core.dll

Clean Workshop release:

  cd ..\personalTooling
  powershell -NoProfile -ExecutionPolicy Bypass -File .\BuildReleases.ps1 -GameVersion v1_4 -ModName BothPerks

Local test staging:

  cd ..\personalTooling
  powershell -NoProfile -ExecutionPolicy Bypass -File .\StageLocalMods.ps1 -GameVersion v1_4 -ModName BothPerks

Upload from:

  ..\releases\BothPerks

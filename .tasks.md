We are developing a Mount & Blade II Bannerlord mod.

Mod name:

  Both Perks

Rules:

- Do not edit or add to `MB_source`; it is decompiled reference material.
- Keep Workshop packages clean: no source, no PDBs, no stale DLLs.
- Build/runtime paths are configured through `ModPaths.local.psd1`.

Current compatibility layout:

- `BothPerks.Bootstrap.dll` is loaded by `SubModule.xml`.
- The bootstrap chooses `compat\v1_2\BothPerks.Core.dll` for Bannerlord 1.2.x.
- The bootstrap chooses `compat\v1_3\BothPerks.Core.dll` for Bannerlord 1.3+.

Current installed reference versions:

- v1_2: `D:\BANNERLORDS\Mount & Blade II Bannerlord`
- v1_3: `D:\BANNERLORDS\Mount & Blade II Bannerlord1.3.15`

Functionality:

- Lets in-scope heroes receive both perks where they qualify.
- Supports manual, auto, and freedom modes through MCM.
- Applies Harmony UI patches for perk selection behavior.
- Adds an XP model for the optional skill XP multiplier.

If anything about version routing or packaging is unclear, ask before changing the release shape.
